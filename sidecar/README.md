# anilume-sidecar

Мост между [anicli-api](https://github.com/vypivshiy/anicli-api) и десктоп-приложением.
Запускается основным процессом и общается с ним по JSON-RPC 2.0 поверх stdio —
одно JSON-сообщение на строку.

## Зачем отдельный процесс

Объекты anicli-api связаны в цепочку и хранят состояние: получить список серий
можно только у живого объекта `Anime`, который, в свою очередь, получается из
объекта `Search`. Адресовать их по ID нельзя. Поэтому сайдкар держит объекты в
памяти и выдаёт наружу строковые **хендлы**, ограниченные LRU-реестром. Когда
объект вытесняется, клиент получает `-32001` и повторяет путь от поиска.

## Протокол

```
→ {"jsonrpc":"2.0","id":1,"method":"catalog.search","params":{"source":"anilibria","query":"клинок"}}
← {"jsonrpc":"2.0","id":1,"result":{"items":[…],"query":"клинок"}}
```

Запросы обрабатываются конкурентно, ответы могут приходить не в порядке
отправки — сопоставляйте их по `id`.

### Методы

| Метод | Параметры | Результат |
| --- | --- | --- |
| `ping` | — | версия, число живых хендлов |
| `sources.list` | — | список источников и источник по умолчанию |
| `catalog.ongoing` | `source` | карточки онгоингов |
| `catalog.search` | `source`, `query` | карточки результатов |
| `catalog.searchMulti` | `sources[]`, `query` | группы по источникам + отдельно упавшие |
| `anime.get` | `handle` карточки | тайтл целиком вместе со списком серий |
| `anime.episodes` | `handle` тайтла | список серий |
| `episode.studios` | `handle` серии | варианты озвучки/плееров |
| `studio.videos` | `handle` озвучки | прямые ссылки, лучшее качество первым |

### Коды ошибок

Стандартные коды JSON-RPC плюс доменные:

| Код | Значение |
| --- | --- |
| `-32001` | хендл вытеснен из реестра — повторить путь от поиска |
| `-32002` | источник недоступен, блокирует по гео или сменил вёрстку |
| `-32003` | сетевая ошибка или таймаут |

Для гео-ограниченных источников в `error.data.hint` приходит подсказка про VPN.

## Разработка

```bash
pip install -e '.[dev]'
pytest                       # 33 теста, сеть не нужна
python3 -m anilume_sidecar   # ручная отладка: пишите JSON в stdin
```

## Сборка бинарника

```bash
python3 build_sidecar.py
```

Кладёт `anilume-sidecar-<target-triple>` в `src-tauri/binaries/` — там его
ожидает Tauri.
